K1VPN builds VPN software for people who want a straightforward way to protect
their internet connection across desktop and mobile devices. Our apps and
connection guides help K1VPN customers connect using supported VPN protocols,
choose a server and manage their connection.

## Open-source projects

### [K1VPN for Linux](https://github.com/K1VPN/k1vpn-linux)

The official Linux desktop client for K1VPN. It uses WireGuard for full-tunnel
VPN connections and includes in-tunnel DNS, server favorites, desktop controls
and an optional kill switch. The source is published under GPL-3.0-only.

The Linux Snap is being prepared for public release. See the repository for the
current availability status, build instructions, security policy and support
links.
